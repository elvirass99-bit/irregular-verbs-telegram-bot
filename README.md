# 📚 Telegram Bot для изучения неправильных глаголов

Бот помогает изучать английские неправильные глаголы через тренировку, словарь и систему повторения.

---

## 🚀 Возможности

- 📖 Словарь с отметкой "знаю / не знаю"
- ❓ Список "На изучение"
- 🎯 Тренировка (5 уровней сложности)
- 🔁 Повтор ошибок
- 📊 Статистика (правильные / ошибки / серия)
- 🔐 Защита паролем

---

## 🧠 Как это работает

1. Добавляешь слова в "На изучение"
2. Проходишь тренировку
3. Исправляешь ошибки
4. Отмечаешь слова как выученные

---

## 🛠 Запуск

```bash
pip install -r requirements.txt
python bot.py
